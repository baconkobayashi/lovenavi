# アンケート知見まとめ（プロンプト反映用）

7名の女性（26〜34歳）によるアンケート結果から抽出した、高評価・低評価のパターンと原則。

---

## 【初回アプローチ】

### 高評価（Aランク）の特徴

- **プロフィールの一点に絞って言及する**。全項目を列挙せず、「気になった部分」を1つ選んで触れると誠実な印象になる
- **自己開示してから質問する**。「私も〇〇が好きで〜、〇〇さんはどうですか？」という流れが返しやすく会話が続く
- **答えやすい質問を1つだけ**。「おすすめは？」より「最近どこか行きましたか？」「最近気になることありますか？」のほうが負担が少ない
- **連絡した理由を示す**。「なぜメッセージしたか」が伝わると安心感・誠実さが増す（例：「〇〇に共感して」「真剣に相手を探していて」）
- **丁寧語 + 「はじめまして」の挨拶**は基本として好印象
- **距離感を保つ表現**（「ゆっくりお話しできたら」「もしよろしければ」）が好まれる
- **適度な絵文字・「笑」**はOK。多すぎると軽く見える

### 低評価（Cランク）の特徴

- **コピペ感がある文章**（「プロフィール、写真からすごく惹かれました」など誰にでも送れそう）
- **「おすすめを教えてください」は回答負担が高い**。まだ親しくない段階では避ける
- **一度に複数の質問**（質問攻め）は圧に感じる
- **タメ口**は初回では厳禁
- **初手でデート・会う提案**（「一緒にショッピング行きませんか？」など）は早すぎて引かれる
- **相手のプロフィール情報を全部列挙**（「26歳で東京にお住まいなんですね」）は監視されているような不快感
- **「共通点がなさそうですが」など自己否定的な書き出し**は「なぜ連絡してきたか不明」になる
- **「どうぞよろしくお願いします！」「もちろん無理にとは言いません」**など過剰にビジネス的・低姿勢な締め
- **「〇〇さんへの印象」を大げさに書く**（「写真の雰囲気から勝手に想像が膨らみました」など）は馴れ馴れしく見える

---

## 【返信メッセージ】

### 高評価（Aランク）の特徴

- **相手の趣味・発言に絡めて自己開示 + 質問**（「私も〇〇が好きで最近は〜にハマってます。〇〇さんは？」）
- **「最近行って良かった場所」「最近気になる映画」**など答えやすい質問
- **デートへの誘い方**：「〇〇（相手の趣味）の話しながら、カフェでも行きませんか？」のように趣味と絡めた気軽な提案が好評
- **LINE交換の誘い方**：「もっと気軽に話したいので、LINE交換しませんか？」や「〇〇の話、LINEで聞かせてください」のように理由を添える
- **関係を温める場合**：返信しやすい話題 + 相手に質問で会話を続ける。「最近ハマっていることありますか？」等
- **断りやすい表現**（「もしよかったら」「都合が合えば」）を入れる

### 低評価（Cランク）の特徴

- **やり取り済みなのに「はじめまして」と書く**
- **目的（デートに誘う・LINE交換など）と無関係な内容になっている**。目的を達成するフレーズが含まれていないと評価されない
- **「近いうちに軽くお茶でも」「漠然とした誘い**は「会おうと思えない」
- **LINE交換の目的なのに、会話を続けるだけで終わっている**パターン
- **「いいですね！なんか良い出会いになりそう」など意味のない褒め言葉**
- **「まだ行くと言っていないのにカフェを調べておきます！」**など先走りすぎる表現
- **「情報交換しませんか」**など、LINEに持ち込む理由が弱い・不自然

---

## 【デートへの誘い（共通）】

### Positive
- 相手の趣味・好みに関連したデート内容を提案する
- ランチ・カフェなど気軽な場所の提案
- 断る余地を残す（「もし都合よければ」）
- ある程度具体的（場所・内容を絞って提案）
- 相手に意見を言える余白を残す（「どう思いますか？」）

### Negative
- 急すぎる日程（今夜・明日など直近）
- 夜遅い時間帯
- 遠すぎる場所
- 場所や内容を全て相手任せにする
- 「1回だけでいいから会って」など圧が強い
- 誘いとは無関係な話を長々とした末に最後だけぼそっと誘う

## プロンプトへの組み込み方針

以下の文言を `generate-message` と `generate-reply` のシステムプロンプトに挿入する：

### 初回アプローチ用（generate-message）に追加するルール

```
【実際の女性の声に基づく品質基準】
以下のルールを必ず守ること：

良いメッセージの条件：
- プロフィールの1項目を選んで具体的に言及する（全項目の列挙は不可）
- 自分のことを少し開示しながら質問する（「私も〇〇です。〇〇さんは？」の形）
- 質問は1つだけ、答えやすいもの（「最近〇〇しましたか？」「最近気になる〇〇は？」）
- 「はじめまして」の挨拶と丁寧な敬語は必須
- なぜメッセージしたかの理由が伝わる内容にする
- 「もしよろしければ」「ゆっくりお話しできたら」など距離感を保つ表現を使う

避けるべき表現：
- 誰にでも送れるような曖昧な褒め言葉（「プロフィールに惹かれました」だけ）
- 「おすすめを教えてください」（負担が大きい）
- 複数の質問を一度に並べる
- タメ口
- 初手でのデート・会う誘い
- 相手の基本情報（年齢・住まい）をそのまま列挙する表現
- ビジネス的な締め（「どうぞよろしくお願いします」）
- 「もちろん無理にとは言いません」など過剰な低姿勢
```

### 返信メッセージ用（generate-reply）に追加するルール

```
【実際の女性の声に基づく品質基準】
以下のルールを必ず守ること：

良いメッセージの条件：
- 相手の趣味・発言に絡めた自己開示をしてから質問する
- 「最近行って良かった〇〇」「最近気になる〇〇」など答えやすい質問を1つ
- 目的が「デートに誘う」場合：相手の趣味に関連した気軽な場所（カフェ・ランチ）を提案し、断りやすい表現（「もしよかったら」）を添える
- 目的が「LINE交換」場合：「もっと気軽に話したい」「〇〇の話、LINEで聞かせてください」など理由を添えて誘う
- やり取り済みの相手に「はじめまして」は使わない（関係値に応じた書き出しにする）

避けるべき表現：
- 目的（デート誘い・LINE交換など）を達成するフレーズが含まれない返信
- 「近いうちに軽くお茶でもどうですか」など曖昧すぎる誘い
- 「〇〇も調べておきます！」など相手がOKする前に先走る表現
- 「情報交換しませんか」など理由が弱いLINE誘い
- 漠然とした褒め言葉のみで終わる返信
```
