# LLMプロンプト仕様

モデル: Google Gemini 2.5 Flash Lite  
出力形式: JSON `{ patterns: [{ tone, message }] }` × 3パターン

---

## 初回アプローチ（generate-message）

**役割:** 初回メッセージ作成の専門家

**入力情報:**

| 項目 | 内容 |
|---|---|
| 相手の関係値 | matching / chatted / met / dating |
| 相手の年齢 | 数値 |
| 相手の居住エリア | 都道府県 |
| 相手の趣味 | テキスト |
| 相手のプロフィール文 | テキスト（任意） |
| 自分の年齢 | 数値 |
| 自分の職業 | テキスト |
| 自分の趣味 | テキスト |
| キャラ設定（tone） | 積極的 / 控えめ / ユーモア系 / 誠実系 |

**制約:**
- 50〜120文字
- 馴れ馴れしすぎず、押しつけがましくない
- 相手のプロフィールに言及する内容を含める

---

## 返信メッセージ（generate-reply）

**役割:** 返信メッセージ作成の専門家

**入力情報:**

| 項目 | 内容 |
|---|---|
| これまでの会話履歴 | `sender` + `text` + `feedback` のリスト |
| 相手の最新メッセージ | テキスト |
| やり取り回数 | 初回 / 2〜5回 / 6〜10回 / 11回以上 |
| 今回の目的 | 会話を続ける / デートに誘う / LINE交換 / 関係を温める |
| 相手のトーン | テンション高め / 普通 / 素っ気ない / わからない |
| 相手の関係値・年齢・エリア・趣味 | 各テキスト |

**会話履歴のフィードバック反映:**

自分のターンに返信結果をラベルとして付与し、LLMが参考にする。

```
自分: 〜〜〜 [✓返信あり]
相手: 〜〜〜
自分: 〜〜〜 [✗既読スルー]
相手: 〜〜〜
```

- `✓返信あり` → そのトーン・内容の傾向を踏襲
- `✗既読スルー` → その書き方を避ける
- `△待ち中` → 参考情報として渡す
- feedbackなし / 相手ターン → ラベルなし

**制約:**
- 30〜100文字
- 相手のメッセージに自然に返す
- 指定した目的を意識した内容
